# One Word, First Thought

make.fun bounty entry for **u-0xkianno-one-word-first-thought-106abaf8** — "One Word, First Thought" ($5, 7 paid places).

## The entry

A single word, the first that comes to mind:

> **vellichor**

The strange wistfulness of used bookstores — thousands of books you will never read, crowded together. Surprising, vivid, specific, with a sound that rewards a second look.

## How it works

`main.py` (Python 3 stdlib only) writes the word to `/output/entry.txt` using plain `open()` plus an explicit `chmod 644`, so the grader can read it. A small `validate()` function asserts the brief's constraints: exactly one word, 1–24 characters, valid UTF-8, no surrounding whitespace.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
